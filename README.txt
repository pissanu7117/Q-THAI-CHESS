วิธีติดตั้ง GitHub Pages
1. สร้าง Repository ใหม่ชื่อ Q-THAI-CHESS
2. Upload index.html ไปที่ root ของ Repository (ไม่ใช่โฟลเดอร์ย่อย)
3. Settings > Pages > Deploy from a branch > main / (root) > Save
4. เปิดลิงก์ GitHub Pages ที่ระบบแสดง

icon.svg เป็นไอคอนทางเลือกสำหรับใช้ในโปรเจกต์
